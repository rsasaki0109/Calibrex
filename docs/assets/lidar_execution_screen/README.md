# Rejected LiDAR execution candidates

Original protocols, all four complete CPU map workers (20 full fits), 288 timed GPU registrations, seven retained warmups, full outputs, candidate code and logs are preserved byte for byte. No candidate is adopted.

Shared committed runtime source is reconstructed from the three indexed source dependencies. Launchers verify imported source; prototype code is bound separately and is not a production backend. Raw point coordinates, binary profiles, and compiler caches are not redistributed. GPU fixture metadata binds private coordinate captures to the already spent public GLIM bag. CPU replay checks recorded bits and receipts; it cannot rerun geometry without the original inputs and CUDA.
