from pathlib import Path
import hashlib,json,shutil,statistics,tarfile
root=Path('docs/assets/cuda_map_fusion');root.mkdir(exist_ok=False)
source=Path('outputs/fused-map-formal-v1')
observation=Path('outputs/fused-map-observation-v1')
protocol=json.loads((source/'protocol.json').read_bytes())
summary=json.loads((source/'summary.json').read_bytes())
attempts=json.loads((source/'attempts.json').read_bytes())
assert len(attempts)==6 and summary['quality_passed']
for name in ('protocol.json','summary.json','attempts.json','benchmark.py.txt','map-benchmark.py.txt'):
    shutil.copyfile(source/name,root/name)
for row in attempts:
    directory=root/row['worker'];directory.mkdir()
    for name in ('measurement.json','result.json'):
        shutil.copyfile(source/row['worker']/name,directory/name)
    shutil.copyfile(source/(row['worker']+'.log'),directory/'worker.log')
for variant in ('prior','current'):
    folder=source/f'sources-{variant}'
    shutil.copyfile(folder/'manifest.json',root/f'sources-{variant}-manifest.json')
    with tarfile.open(root/f'sources-{variant}.tar.gz','w:gz') as archive:
        archive.add('LICENSE',arcname='LICENSE',recursive=False)
        for path in sorted((folder/'src').rglob('*.py')):
            archive.add(path,arcname=path.relative_to(folder).as_posix(),recursive=False)
for original,name in [('tests/unit/test_cuda_map_fusion.py','fusion-tests.py.txt'),
                      ('tests/unit/test_cuda_spatial_build.py','spatial-tests.py.txt'),
                      ('tests/unit/test_cuda_lidar_map_adapter.py','map-tests.py.txt'),
                      ('tools/schemas/cuda_map_pipeline_comparison.schema.json','comparison.schema.json'),
                      (__file__,'publisher.py.txt')]:
    shutil.copyfile(original,root/name)
for name in ('observation.json','observation.schema.json','observer.py.txt'):
    shutil.copyfile(observation/name,root/name)
observed=json.loads((root/'observation.json').read_bytes())
assert observed['exit_code']==0 and not any(row['foreign'] or row['unknown'] for row in observed['samples'])
compilation={variant:[json.loads((root/f'{r:02d}-{variant}/measurement.json').read_bytes())['frozen_provenance']['nvrtc_compilation'] for r in range(3)] for variant in ('prior','current')}
seconds={variant:statistics.median(row['seconds'] for row in rows) for variant,rows in compilation.items()}
assert [row['calls'] for row in compilation['prior']]==[63]*3
assert [row['calls'] for row in compilation['current']]==[17]*3
text=f'''# Fused FP64 CUDA map evaluation

Three alternating previous/current fresh-process pairs with separate initially
empty CuPy caches retain exact complete evaluation results and reduce first-use
time. This measures the public KITTI copied-sensor execution control, not
independent two-sensor accuracy or reference-odometry generation.

| Scope | Previous median | Fused median | Observed speedup |
| --- | ---: | ---: | ---: |
| Complete fresh worker | {summary['whole_median_seconds']['prior']:.3f} s | {summary['whole_median_seconds']['current']:.3f} s | {summary['whole_speedup']:.3f}x |
| Complete calibration/evidence API | {summary['api_median_seconds']['prior']:.3f} s | {summary['api_median_seconds']['current']:.3f} s | {summary['api_speedup']:.3f}x |
| Nested NVRTC compilation | {seconds['prior']:.3f} s | {seconds['current']:.3f} s | {seconds['prior']/seconds['current']:.3f}x |
| Compiled programs per worker | 63 | 17 | — |

The API includes target preparation, all fits, covariance, holdout, signed
controls and jackknife. Worker time additionally includes process imports,
raw input reads, hashes, saved artifacts and frozen import verification.
Compilation is a nested scope; component ratios must not be multiplied. These
first-use results are not a claim about the speedup with already warm caches.

The new single CUDA module captures tree compaction, uncertainty flags, native
repair scatters, source-ordered residual packing, Jacobians and robust products.
Existing exact spatial traversal, FP64 distances, covariance/eigensolves, BLAS
reductions and native numerical repairs keep their semantics. There is no
neighbor-count specialization, no gyro device path and no implicit geometry or
motion grid. Sampling, neighbor counts, iterations and evaluation budgets are
unchanged. CPU/default execution remains ROS-independent and imports no CuPy.

All three full evaluation outputs match exactly, including transforms,
covariance, signed controls, holdout, jackknife and decisions. Each worker keeps
six samples, 762,118 map rows and 9,147,116 query rows. The candidate actually
executes 276 fused map kernels over 8,384,998 residual input rows and 3,838,813
normal-system rows. Device construction and final arrays retain the same point
order. Original GPU snapshots and the fused path retain byte-identical residuals,
Hessians and gradients in independent real-device tests.

Input: KITTI raw sequence `2011_09_30_drive_0018_sync`, scans 115, 230 and 345,
copied central scans, fixed 0.01 m target noise and generated rigid poses. Raw
scans are not redistributed. This is an identity execution control, not a
physical two-sensor ground-truth calibration.

No foreign or unknown CUDA compute process appeared in {len(observed['samples'])}
ten-second observations. Sampling does not guarantee continuous GPU exclusivity,
detect all graphics activity or reserve CPU resources. Workers use one
BLAS/OMP/MKL thread. Only the owned cohort would be stopped on interference.
No process IDs, names or hardware models are published.

Baseline: `{protocol['commits']['prior']}`. Measured candidate:
`{protocol['commits']['current']}`. The publication index binds all six workers,
both source trees, launchers, schemas, tests, observer and publisher. Both spatial
and fused arithmetic shader bytes participate in the runtime identity.

```bash
python -m tools.audit_cuda_map_pipeline docs/assets/cuda_map_fusion
```
'''
(root/'README.md').write_text(text,encoding='utf-8',newline='\n')
files={p.relative_to(root).as_posix():hashlib.sha256(p.read_bytes()).hexdigest() for p in root.rglob('*') if p.is_file()}
(root/'publication-index.json').write_text(json.dumps({
    'schema_version':'calibrex.cuda_map_pipeline/v0.1','record_type':'publication',
    'files':files,'provenance':{'protocol_sha256':hashlib.sha256((root/'protocol.json').read_bytes()).hexdigest()}},indent=2)+'\n',encoding='utf-8',newline='\n')
print({'files':len(files)+1,'whole_speedup':summary['whole_speedup'],'api_speedup':summary['api_speedup'],'quality_exact':True})
