"""Compare each joint output with its matching three single-frame results."""
import hashlib
import json
import shutil
from pathlib import Path
import numpy as np
from pydantic import BaseModel, ConfigDict
from tools.run_camera_lidar_development_matrix import DevelopmentMatrixPlan, MatrixResult

root=Path('/workspace/work/external-comparison-20261028/preprocessed/joint-20261028')
out=Path('/workspace/Calibrex/docs/assets/joint_assisted_20261028')
previous=Path('/workspace/Calibrex/docs/assets/assisted_matrix_20261028/matrix.json')
plan=DevelopmentMatrixPlan.model_validate_json((out/'plan.json').read_text())
result=MatrixResult.model_validate_json((root/'matrix.json').read_text())
baseline=MatrixResult.model_validate_json(previous.read_text())
assert len(result.records)==4
assert {r['case_id'] for r in result.records}=={f'{d.id}-{p.id}' for d in plan.drives for p in plan.perturbations}
assert result.plan_sha256==hashlib.sha256((out/'plan.json').read_bytes()).hexdigest()
assert result.driver_sha256==plan.source_sha256['tools/run_joint_assisted_experiment.py']

class PairedCase(BaseModel):
    model_config=ConfigDict(extra='forbid',allow_inf_nan=False)
    case_id: str
    method: str
    valid_output: bool
    recovered: bool
    joint_rotation_deg: float | None
    joint_translation_m: float | None
    single_rotation_median_deg: float
    single_translation_median_m: float
    translation_delta_vs_single_m: float | None
    translation_improved_vs_single_median: bool
    translation_improved_vs_seed: bool

class Summary(BaseModel):
    model_config=ConfigDict(extra='forbid')
    scope: str
    paired_cases: list[PairedCase]
    recovered: dict[str,int]
    translation_improved_vs_single_median: dict[str,int]
    baseline_sha256: str
    artifact_sha256: dict[str,str]

for name in ['matrix.json','matrix.schema.json','original-entrypoint.sh','runtime-entrypoint.sh','job.sh']:
    shutil.copyfile(root/name,out/name)
shutil.copyfile('/workspace/work/joint-assisted-20261028.log',out/'execution.log')
shutil.copyfile(__file__,out/'publish.py.txt')
pairs=[]
for record in result.records:
    target=out/record['case_id'];target.mkdir(exist_ok=True)
    source=root/record['case_id']
    for p in source.iterdir():
        if p.suffix in ['.json','.log']:
            shutil.copyfile(p,target/p.name)
    mapping=json.loads((source/'frontend.json').read_text())
    for name,identity in mapping.items():
        assert hashlib.sha256((source/name).read_bytes()).hexdigest()==identity['sha256']
    native=json.loads((source/'d2d.json').read_text())
    assert native['driver_sha256']==plan.source_sha256['tools/run_joint_stereo_d2d.py']
    assert native['result']['final_evaluation']['evaluated_frame_count']==3
    assert native['input_sha256'][str(source/'calib.json')]==hashlib.sha256((source/'calib-frontend.json').read_bytes()).hexdigest()
    for method in ['d2d','koide']:
        old=[r['methods'][method] for r in baseline.records if r['drive']==record['drive'] and r['case_id'].endswith('-'+record['seed'])]
        assert len(old)==3 and all(r['valid_output'] for r in old)
        median_rotation=float(np.median([r['rotation_deg'] for r in old]))
        median_translation=float(np.median([r['translation_m'] for r in old]))
        new=record['methods'][method]
        pairs.append(PairedCase(case_id=record['case_id'],method=method,
            valid_output=new['valid_output'],recovered=new['recovered'],
            joint_rotation_deg=new['rotation_deg'],joint_translation_m=new['translation_m'],
            single_rotation_median_deg=median_rotation,single_translation_median_m=median_translation,
            translation_delta_vs_single_m=new['translation_m']-median_translation if new['valid_output'] else None,
            translation_improved_vs_single_median=new['valid_output'] and new['translation_m']<median_translation,
            translation_improved_vs_seed=new['valid_output'] and new['translation_m']<record['initial']['translation_m']))
summary=Summary(scope='four correlated spent-data joint cases; paired descriptive diagnostics, not superiority',
    paired_cases=pairs,recovered={m:sum(p.recovered for p in pairs if p.method==m) for m in ['d2d','koide']},
    translation_improved_vs_single_median={m:sum(p.translation_improved_vs_single_median for p in pairs if p.method==m) for m in ['d2d','koide']},
    baseline_sha256=hashlib.sha256(previous.read_bytes()).hexdigest(),
    artifact_sha256={str(p.relative_to(out)):hashlib.sha256(p.read_bytes()).hexdigest() for p in out.rglob('*') if p.is_file() and p.name not in ['summary.json','summary.schema.json']})
(out/'summary.json').write_text(summary.model_dump_json(indent=2)+'\n')
(out/'summary.schema.json').write_text(json.dumps(Summary.model_json_schema(),indent=2)+'\n')
Summary.model_validate_json((out/'summary.json').read_text())
for p in pairs:
 print(p.case_id,p.method,f'{p.joint_rotation_deg:.4f} deg / {p.joint_translation_m:.4f} m',f'trans delta {p.translation_delta_vs_single_m:+.4f} m',p.recovered)
print(summary.recovered,summary.translation_improved_vs_single_median)
