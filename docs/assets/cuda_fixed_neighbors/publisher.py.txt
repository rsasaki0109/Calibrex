from pathlib import Path
import hashlib,json,shutil,tarfile
root=Path('docs/assets/cuda_fixed_neighbors');root.mkdir(exist_ok=False)
source=Path('outputs/fixed-neighbor-map-formal-v1')
observation=Path('outputs/fixed-neighbor-map-observation-v1')
protocol=json.loads((source/'protocol.json').read_bytes())
summary=json.loads((source/'summary.json').read_bytes())
attempts=json.loads((source/'attempts.json').read_bytes())
assert len(attempts)==6 and summary['quality_passed']
for name in ('protocol.json','summary.json','attempts.json','benchmark.py.txt','map-benchmark.py.txt'):
    shutil.copyfile(source/name,root/name)
for row in attempts:
    directory=root/row['worker'];directory.mkdir()
    for name in ('measurement.json','result.json'):
        shutil.copyfile(source/row['worker']/name,directory/name)
    shutil.copyfile(source/(row['worker']+'.log'),directory/'worker.log')
for variant in ('prior','current'):
    folder=source/f'sources-{variant}'
    shutil.copyfile(folder/'manifest.json',root/f'sources-{variant}-manifest.json')
    with tarfile.open(root/f'sources-{variant}.tar.gz','w:gz') as archive:
        archive.add('LICENSE',arcname='LICENSE',recursive=False)
        for path in sorted((folder/'src').rglob('*.py')):
            archive.add(path,arcname=path.relative_to(folder).as_posix(),recursive=False)
for original,name in [('tests/unit/test_cuda_fixed_neighbors.py','fixed-tests.py.txt'),
                      ('tools/schemas/cuda_fixed_neighbors_comparison.schema.json','comparison.schema.json'),
                      (__file__,'publisher.py.txt')]:
    shutil.copyfile(original,root/name)
for name in ('observation.json','observation.schema.json','observer.py.txt'):
    shutil.copyfile(observation/name,root/name)
observed=json.loads((root/'observation.json').read_bytes())
assert observed['exit_code']==0 and not any(row['foreign'] or row['unknown'] for row in observed['samples'])
text=f'''# Rejected fixed-neighbor CUDA trial

The prototype is rejected. Three alternating fresh-process pairs with separate
initially empty CuPy caches produce whole medians of
{summary['whole_median_seconds']['prior']:.3f} s (previous) and
{summary['whole_median_seconds']['current']:.3f} s (prototype),
{summary['whole_speedup']:.3f}x. API medians are
{summary['api_median_seconds']['prior']:.3f} s and
{summary['api_median_seconds']['current']:.3f} s,
{summary['api_speedup']:.3f}x. Active runtime changes are reverted.

The query compiler specializes the requested neighbor count and expands sorted
candidate updates into constant slots. Point membership, FP64 distance arithmetic,
distance/point-ID ordering, tree traversal and numerical repair policies are
preserved. All three complete API evaluations (transforms, covariance, signed
controls, holdout, jackknife and decisions) match exactly. Each worker retains
six samples, 762,118 map rows and 9,147,116 device query rows. No workload budget
is reduced. GPU parity tests for all 1–17 neighbor counts remain frozen here.

An earlier fixed-order shared-cache pilot appeared much faster: the previous
worker ran first with a cold cache and the prototype reused the generated
compilation cache. That pilot cannot establish acceleration. Warm query kernel
improvements likewise do not establish complete calibration speed. Cold/full
measurements take precedence. A separate compiler diagnostic measured only
about 0.9 s for the two specialized query modules; this does not explain all
whole-worker variation, and CPU resources were not reserved.

Public KITTI raw sequence `2011_09_30_drive_0018_sync`, scans 115, 230 and 345,
forms a copied-sensor identity execution control with fixed 0.01 m noise and
generated rigid poses. It does not establish independent two-sensor extrinsic
accuracy or include reference-odometry generation. Full worker time includes
imports, input reading, preparation, compilation, fits, holdout, signed controls,
jackknife, hashes, saved artifacts and frozen-import verification. Raw scans
are not redistributed. Workers use one BLAS/OMP/MKL thread each.

No foreign or unknown CUDA compute process was detected in {len(observed['samples'])}
ten-second observations. Periodic sampling does not establish continuous GPU
exclusivity, detect all graphics activity or reserve CPU resources. Only the
owned cohort would be terminated on interference. Process IDs and names are
not published.

Baseline commit: `{protocol['commits']['prior']}`. Measured rejected source:
`{protocol['commits']['current']}`. The index binds both full source trees,
all six workers, launchers, schemas, device tests, observer and publisher.

```bash
python -m tools.audit_cuda_fixed_neighbors docs/assets/cuda_fixed_neighbors
```

Reproduction requires the measured commit above, the three raw inputs matching
the protocol hashes and the frozen launcher. The active runtime retains the
previous generic query implementation.
'''
(root/'README.md').write_text(text,encoding='utf-8',newline='\n')
files={p.relative_to(root).as_posix():hashlib.sha256(p.read_bytes()).hexdigest()
       for p in sorted(root.rglob('*')) if p.is_file()}
(root/'publication-index.json').write_text(json.dumps({
    'schema_version':'calibrex.cuda_fixed_neighbors/v0.1','record_type':'publication',
    'files':files,'provenance':{'protocol_sha256':hashlib.sha256((root/'protocol.json').read_bytes()).hexdigest()}},indent=2)+'\n',encoding='utf-8',newline='\n')
print({'files':len(files)+1,'whole_speedup':summary['whole_speedup'],'exact_quality':True})
