import json
import shutil
from pathlib import Path
import jsonschema
from tools.run_camera_lidar_development_matrix import digest

source=Path('/workspace/work/broader-models-inputs-20261029')
runs=Path('/workspace/work/broader-models-results-20261029')
root=Path('docs/assets/broader_models_20261029')
for name in ['preparation.json','preparation.schema.json']:
    shutil.copyfile(source/name,root/name)
for path in runs.rglob('*'):
    if path.is_file() and path.suffix in ['.json','.log']:
        dest=root/'runs'/path.relative_to(runs)
        dest.parent.mkdir(parents=True,exist_ok=True)
        shutil.copyfile(path,dest)
for name,path in [('preparation.log',Path('/workspace/work/broader-models-preparation-20261029.log')),
                  ('execution.log',Path('/workspace/work/broader-models-run-20261029.log'))]:
    shutil.copyfile(path,root/name)
plan=json.loads((root/'plan.json').read_text())
prep=json.loads((root/'preparation.json').read_text())
assert len(prep['drives'])==2 and all(d['status']=='completed' for d in prep['drives'])
for d in plan['drives']:
    for frame in d['frames']:
        meta=source/d['id']/f'frame-{frame}'/'frontend.json'
        dest=root/'frontends'/d['id']/f'frame-{frame}'
        dest.mkdir(parents=True,exist_ok=True)
        shutil.copyfile(meta,dest/'frontend.json')
        shutil.copyfile(meta.with_suffix('.schema.json'),dest/'frontend.schema.json')
for p in root.rglob('*.json'):
    schema=p.with_suffix('.schema.json')
    if schema.exists():jsonschema.validate(json.loads(p.read_text()),json.loads(schema.read_text()))
for filename,sha in plan['source_sha256'].items():
    assert digest(Path(filename))==sha
matrix=json.loads((root/'runs/matrix.json').read_text())
assert len(matrix['records'])==4
assert len({c['case_id'] for c in matrix['records']})==4
for c in matrix['records']:
    assert set(c['methods'])=={'d2d','pandey'}
    assert all(m['returncode']==0 and m['status']=='converged' for m in c['methods'].values())

### Decision and scope

The observed D2D rotation/translation tradeoff persists on two recordings outside
the earlier four-drive refinement loop. The alternative image/intensity objective
also does not solve the problem under its existing settings. No frontend,
optimizer defaults or recovery thresholds are promoted or tuned from this result.

The assisted-input method-comparison series now has samples from **six distinct
KITTI raw recordings**. This is sparse three-frame coverage, not completion of
the separate all-55-drive capture/replay requirement. Same-day recordings do not
add rigs or dataset families; no fresh evaluation or SOTA claim is supported.

Next prioritize a failure-aware calibration quality check on the full six-DoF
output, using independent measurements/frames and reporting false acceptance,
before trusting an objective's convergence flag. A calibrated rejection mechanism
must preserve coverage as well as reject the 0015-negative failure; fitting a
threshold directly to these four outcomes would not validate it.
